**Shared state resets (S1.42).** Curved-model state is cleared by five
`_reset_*_state()` helpers on `VisContent` — the single definition of each
group's cleared values, called from both `__init__` and the clear/abort
paths. Add a new curved state field to its helper, **not** to `__init__`,
or `clear_curved_model()`/`_abort_geodesic_precompute()` will leave it
stale. They are pure state assignment: `ps.remove_*` calls stay at the call
sites. Note `_reset_toolpath_playback_state()` predates this and is *not*
the same shape — it calls `_clear_gcode_print_mesh()`, so it is not
`__init__`-safe.
