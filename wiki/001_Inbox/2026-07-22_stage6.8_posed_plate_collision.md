# Stage 6.8 — Posed-plate collision: arm always blocked, TCP optional

## Why
The "valid toolpath" gate (`_branch_clears_ground`, line 2546) tests all seven moving
meshes against **world z=0**, not against where the build plate actually is, and treats
the arm and nozzle identically (the `reject_below_ground` toggle rejects everything or
nothing). We want a physical rule: the **arm links are always blocked from passing
through the actual posed plate**, while the **TCP/nozzle may optionally pass through it**
(a toggle). This replaces the crude z=0 proxy.

## Confirmed decision (user, 2026-07-22)
Check against the **actual posed build-plate plane** (`self.T_user_frame`), replacing
the world-z=0 `reject_below_ground` toggle entirely. Arm links always blocked below the
plate; a new `allow_tcp_through_plate` toggle lets the nozzle tip through.

## The plate plane
Derive from the live 4×4 `self.T_user_frame` (built in `load_build_plate`, line 340):
- point = plate top face = `T_user_frame[:3,3] + PLATE_THICKNESS_MM * T_user_frame[:3,2]`
  (print surface sits `PLATE_THICKNESS_MM` above plate origin along local +Z — the same
  offset `load_build_plate` applies to the mesh at line 359).
- normal = `T_user_frame[:3,2]` (plate local +Z, up). A vertex clears the plate iff
  `(world - point) @ normal >= -tolerance`.
`T_user_frame` (full 4×4) is already in both precompute cache keys, so no extra cache
field is needed for the plate pose.

## Backend changes — geometry_backend.py
1. New state flag in `__init__` (line ~193, replacing `reject_below_ground`):
   `self.allow_tcp_through_plate = False`. Default False = nozzle also blocked (safe
   default, mirrors old default-ON reject spirit); True lets the TCP dip below the plate.
2. Reuse the signed-distance primitive. `_nozzle_clears_plane` (line 2515) already does
   corners-first / exact-vertices-fallback signed-distance against a plane for mesh index
   6. Generalize it (or add `_meshes_clear_plane(angles, indices, point, normal, tol)`)
   to take a set of moving-geometry indices — call it for arm links `[0:6]` (zero
   tolerance) and the nozzle `[6]`. `_moving_geometry_deltas` (line 2472) + `rest_verts` /
   `moving_geometry_rest_bbox_corners` provide per-mesh world geometry, indexed 0..5 =
   links, 6 = nozzle.
3. Rewrite `_branch_clears_ground(self, joint_angles_deg, plane=None)` (line 2546) as:
   - **Plate check (always, both paths):** build the plate plane from `T_user_frame`.
     Reject if any arm-link vertex (0–5) is below the plate (zero tolerance). Reject the
     nozzle (6) if below the plate unless `self.allow_tcp_through_plate`.
   - **Tangent-plane nozzle check (curved only, `plane is not None`):** unchanged —
     `_nozzle_clears_plane` against the waypoint's own surface tangent plane (S1.37), a
     separate obstacle (the mockup shell), layered on top of the plate check.
   - Delete the z=0 branch (`reject_below_ground` / `moving_geometry_bbox_min_z` /
     `moving_geometry_min_z`); the generalized signed-distance path supersedes the
     z=0-specific min-z helpers.
4. Cache invalidation: in `_toolpath_cache_meta` (line 1738) and `_curved_toolpath_cache_meta`
   (line 1762), replace the `reject_below_ground` key with `allow_tcp_through_plate`; bump
   `PRECOMPUTE_CACHE_VERSION` 3 → 4 (line 147). The toggle changes which IK branch is
   accepted per waypoint, so solved joint paths depend on it. Existing caches rebuild once.

## GUI changes — gui_panel.py
Replace the "Reject poses below ground (z<0)" checkbox (lines 210–213) with an
**"Allow TCP through build plate"** checkbox bound to `content.allow_tcp_through_plate`,
disabled while `precompute_running`, in the same "Toolpath Settings" tree node.

## Consequence / workflow note
With the plate check always-on against the real plate, a curved precompute at the
**default plate pose** (plate at world z≈0, mockup above it) rejects early: the arm
reaches to ~z=-300mm, below the plate. This is correct — the fix is to reposition the
plate lower via the existing Build Plate Orientation Move/Save/Load controls
(`gui_panel.py:237+`) until the arm clears it (the "put the plate lower than the arm"
workflow). This replaces the old escape hatch of unchecking `reject_below_ground` with a
physically-grounded one: move the obstacle, don't disable the check.
