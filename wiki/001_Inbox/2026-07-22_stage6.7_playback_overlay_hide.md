# Stage 6.7 — Hide guide overlays during toolpath playback

## Why
The progressive bead reveal already works (6.6: `_build_curved_beads`,
`_init_curved_toolpath_playback`, the sorted-cutoff reveal in
`advance_toolpath_playback`). The problem is purely visual: the geodesic path
curves, travel moves, print-order gradient, and orientation-frame triads stay drawn
on top of the growing beads during playback, so you can't see the object being
formed. `apply_live_layer_visibility` toggles overlays only on layer selection, never
on playback state — nothing hides the guides when Run is pressed. 6.7 closes that seam.

## Confirmed decision (user, 2026-07-22)
On Run, hide the geodesic/order-feed curves, travel moves, base toolpath curve, and
orientation-frame triads. **Keep** the print-surface mesh(es) and the progressively-
growing bead mesh visible. Restore all overlays on Reset.

## Backend changes — geometry_backend.py
1. New state flag in `__init__` (near playback state, ~line 200–215):
   `self.playback_active = False`. True from when a playback run actually starts until
   Reset. Must be distinct from `playback_running` (which flips off on Pause) so
   overlays stay hidden through a pause; only Reset restores them.
2. `apply_live_layer_visibility(self, layer)` (line 1435): when `self.playback_active`
   is True, force-disable the three overlay curve networks (`overlay`/`travel`/`orient`)
   and the `base_curve`, regardless of the stack rule; `surface` and `bead` keep
   following `visible = (i <= layer)`. Keep the existing `ps.has_curve_network(...)`
   guards. Net effect during playback: stacked surfaces + growing beads only.
3. `run_toolpath_playback(self)` (line 2223): after the run actually starts
   (`playback_running = True`, line 2239), set `playback_active = True` and, for the
   curved case, call `apply_live_layer_visibility(self.toolpath_source)` so overlays
   hide on the click. Planar source (-1): `apply_live_layer_visibility` early-returns
   unless `curved_model_loaded`, so it's a safe no-op — the planar `G-code Print` mesh
   *is* the playback mesh, no separate overlays to hide.
4. `reset_toolpath_playback(self)` (line 2209): set `playback_active = False` and
   re-apply `apply_live_layer_visibility(self.toolpath_source)` (curved) to restore the
   guide view.

## GUI changes — gui_panel.py
None. Existing Run/Reset buttons (lines 179–200) already call `run_/reset_toolpath_playback()`;
the visibility coupling rides inside those backend calls. Frame pump unchanged.

## Not in scope
No new playback/reveal math — 6.6 already ships it. 6.7 is only the visibility gating
that makes the reveal observable.
