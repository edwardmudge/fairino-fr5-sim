# Fairino FR5 Simulation

A Python-based 3D visualisation tool for a 6-degree-of-freedom Fairino FR5 manipulator. 

## Dependencies

* Python 3.12
* Polyscope 2.6.1
* NumPy 2.5.0
* Trimesh 4.12.2

## Usage

```bash
git clone https://github.com/edwardmudge/fairino-fr5-sim.git
cd fairino-fr5-sim
pip install -r requirements.txt
python main.py
```
